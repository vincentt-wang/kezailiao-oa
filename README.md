# 蚵仔寮　LINE 官方帳號原型

11th Design For Taiwan 學生工作坊產出。**非梓官區漁會官方發布，僅供討論。**

## 這是什麼

一個可以真的對話的 LINE 官方帳號模擬器，用來討論「把買魚、料理、帶走接成一條路」這件事。

- `index.html` — 展示頁與模擬器
- `knowledge.js` — 知識庫與判定系統（入口路由、事實庫、出口防線）
- `img/` — 2026/08/08 現場拍攝

## 架構

沿用卡米克 LINE 機器人的做法：**入口路由 → 知識庫 → 出口防線**。
客人的問法有限，窮舉問法比窮舉機器人可能亂講的話可靠。

每一條事實都標了來源。查不到來源的不寫。

## 要維護的只有一個東西

`knowledge.js` 最上面的 `TODAY`，欄位少於十個，一天五分鐘可更新。
